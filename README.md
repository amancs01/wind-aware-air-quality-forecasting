 # Wind-Aware Air Quality Forecasting

Final Year Major Project

## Objective

Develop an Explainable Wind-Aware Spatio-Temporal Graph Neural Network (GAT-GRU) for PM2.5 forecasting in Kathmandu Valley.

## Tech Stack

- Python
- Pandas
- PyTorch
- OpenAQ
- Open-Meteo
- FastAPI (later)
- React (later)

## Project Structure

- Data Collection
- Data Preprocessing
- Graph Construction
- Model Training
- Explainability
- Dashboard
